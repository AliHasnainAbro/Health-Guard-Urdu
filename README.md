# Health-Guard-Urdu
HealthGuard Urdu is an AI-powered health misinformation detection system for Urdu-language content in Pakistan. It was developed as a submission for the 2026 IEEE Technology Summit AI Founder Showcase (Ideation track, Budapest, October 1–2, 2026) and later adapted for the Bano Qabil AI Hackathon Pakistan 2026, hosted by Alkhidmat Foundation.
